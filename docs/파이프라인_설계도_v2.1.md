**철학:** 예측 안 함. "어디가 오를까"를 점치지 않고 "지금 어디가 움직이고 있나"만 실측해서 후보를 좁힘. 타이밍·매수 판단은 전적으로 사용자 몫. 파이프라인은 후보를 좁혀주고 갭에 안 물리게 지켜주는 역할까지만.

**2단계 구조:**
1. **스캐너(모델 1회)** — 실측만, 검색·해석
2. **오케스트레이터가 직접** — 실측 데이터를 정렬·필터해서 워치리스트 작성. 새로 검색하지 않음.

## 종목을 뽑는 기준

1. **일단 움직인 놈만 본다.** 방향 무관, 등락 컸던 개별주 우선. 소스: 거래대금 상위(Most Active) + "오늘 큰 무버" 뉴스 검색.
2. **"컸다"의 기준은 종목마다 다르게.** 고정 %가 아니라 그 종목의 평소 하루 변동폭 대비 2배 이상(state/기준변동표.md). 시장 역행 무브는 1.5배로 완화. 52주 신고가·신저가 경신은 등락 작아도 인정.
3. **시총 100억$ 이상만.** 유동성·셋업 신뢰도 필터.
4. **왜 움직였는지 + 재료 생존 판별.** "진행형" / "소진" / "불명" 셋 중 하나. 떨어진 종목도 재료가 살아있으면 포함. 소진은 제외.
5. **ETF는 후보로 안 뜸.** 10종(XOP·XLV 등)은 내부 레이더 — 테마 신호 뜨면 그 안의 대장주 개별 실측으로 전환.
6. **한국 종목은 코스피가 실제로 움직인 날만**, 미국 동조 티커(SMH·MU 등) 병기.

## 최종 산출물 (WATCHLIST.md)

- **개수:** 미국 개별주 5~8개(최대 10) + 국내 0~3개. 억지로 안 채움 — "볼 것 없음"도 정답.
- **종목당 4줄:** 무브 실측 / 원인+재료 판별 / 갭 리스크(1주 내 실적·이벤트) / 사이즈 힌트
- **레짐 한 줄:** 공격/중립/수비 — VIX·금리·유가·지수로 판정, 사이징 배수에만 사용
- **갭 캘린더:** 다음 2주 실적·경제지표·상시 리스크
- **사이징:** 계좌 1~2% ÷ 손절폭 = 수량 역산. 기계식, 추정 없음.

## 피드백 루프

매일 리스트를 state/워치리스트_로그.md에 축적 → "주간리뷰" 요청 시 실제 가격과 대조 채점 (리스트가 실제로 움직였나 / 갭 경고가 맞았나 / 매매가 리스트 안이었나). 데이터로만 개선.

**버린 것:** 시나리오 확률 예측, EV 랭킹, 옵션 베팅 버킷, 실적일 하드 배제(→경고 라벨), 방어주 상위 로직. 이유: 예측은 검증 불가능한 가짜 정밀성.
